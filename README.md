# 截图打码工具 v1.1

给截图批量打码的小软件。高斯模糊强度可实时调整、可即时预览，
支持一次处理整批图片，也可以从命令行调用。

> 需要 **PC / 手机通用的界面**？访问 `https://apx201.github.io/Screenshots_blur_web`：
> 同时适配电脑和手机（宽屏双栏、窄屏竖排），功能与本程序基本一致。

界面参考 **Minecraft 基岩版 Ore UI** 的暗色设计。

---

## 一、快速开始

1. 双击 **`启动打码工具.vbs`**（不会弹黑窗）。
   - 如果双击没反应，改用 **`启动打码工具(调试).bat`**，它会保留控制台并显示具体错误。
2. 点「**添加图片**」选择截图，或点「**添加文件夹**」一次导入整个目录（自动包含子文件夹）。
3. 用「**模糊强度**」滑块调节高斯模糊程度，左下角的「区域放大预览」会实时显示 1:1 效果。
4. 点「**开始批量打码**」。结果默认保存在 *第一张图片所在目录\打码输出*，原图不会被修改。

> 默认打码区域为左下角的 UID 位置。
> 如果换用其它分辨率/机型的截图，拖动预览图上的白色方框调整一次即可（所有图片共用同一相对位置）。

## 二、界面说明

| 区域 | 作用 |
| --- | --- |
| 图片列表 | 添加 / 移除图片，点选可切换预览；支持 Ctrl / Shift 多选 |
| 打码区域 | 拖动方框调整位置；`+ 新区域` 可再框一处（如昵称、坐标）；X/Y/宽/高 可输入百分比精确对齐 |
| 打码效果 | 高斯模糊 / 马赛克 / 纯色遮盖（绿色选中项），模糊强度、边缘羽化 |
| 输出 | 输出目录、文件名后缀、JPG/WebP 画质 |
| 区域放大预览 | 用**原始分辨率**渲染选中区域的打码结果，直接确认数字是否还看得清 |
| 日志 | 处理进度与失败原因 |

**鼠标操作**：空白处拖动＝新建区域；框内拖动＝移动；四角小方块＝缩放；按住右键＝临时看原图；
`Delete` 删除选中区域；`Ctrl+O` 添加图片；`Ctrl+Enter` 开始批量。

## 三、模糊强度怎么算

强度是**按图片宽度归一化**的，所以同一套参数在不同分辨率的截图上效果一致：

```
实际模糊半径(px) = 图片宽度 × 强度 / 1000
```

- 3168px 宽的截图，强度 `7` → 半径约 **22px**（默认值，能把整行 UID 抹成一片）。
- 强度 `3` 左右会留下可见的色块痕迹，`12` 以上基本是一片平滑的灰。
- 马赛克模式下，强度换算的是**方块边长**；纯色遮盖模式与强度无关。

## 四、命令行批量（可选）

```bat
:: 用默认参数处理整个文件夹
python uid_blur.py --cli -i "D:\截图" -o "D:\截图\打码输出"

:: 自定义强度、马赛克、多个区域
python uid_blur.py --cli -i "D:\截图" -o "D:\out" --strength 12 --mode mosaic
python uid_blur.py --cli -i "D:\截图" --rect 0.079,0.958,0.146,0.988 --rect 0.05,0.08,0.32,0.22
```

| 参数 | 说明 |
| --- | --- |
| `-i / --input` | 图片文件或文件夹（可多个） |
| `-o / --output` | 输出目录，默认「第一张图片所在目录/打码输出」 |
| `--strength` | 模糊强度，默认 7 |
| `--mode` | `gaussian` / `mosaic` / `solid` |
| `--feather` | 边缘羽化像素，默认 2 |
| `--rect` | 打码区域 `x0,y0,x1,y1`，0~1 相对坐标，可重复 |
| `--suffix` | 输出后缀，默认 `_已打码` |
| `--quality` | JPG/WebP 画质，默认 95 |
| `--no-recursive` | 文件夹不递归子目录 |

## 五、常见问题

**打码位置偏了？**
在预览图上把白色方框拖到数字上，或直接改「打码区域」里的 X/Y/宽/高，然后重新批量。
右侧「恢复默认」可以回到预设的左下角位置。

**会不会改坏原图？**
不会。原图只读，结果另存到输出目录，文件名加后缀 `_已打码`。同名文件会被覆盖（只覆盖输出目录里的）。

**输出文件为什么比原图大？**
JPG 默认用画质 95 + 无色度抽样重存。想更小可以把「画质」调到 85 左右。

**图片是竖屏 / 别的机型？**
区域用相对比例保存，会自动按比例缩放；如果 UID 位置差异较大，拖动一次即可。

**隐私方面？**
输出图不写入 EXIF（相机/设备信息），文件名后缀可自定义。

## 六、文件说明

```
截图打码工具\
├─ 启动打码工具.vbs          ← 双击运行（推荐，无控制台窗口）
├─ 启动打码工具(调试).bat     ← 出错时用，能看到报错
├─ uid_blur.py               ← 主程序（图形界面 + 命令行）
├─ ore_ui.py                 ← Ore UI 风格控件（按钮 / 滑块 / 标签页 / 滚动条）
└─ README.md
```

依赖：Python 3.9+ 与 Pillow（`pip install pillow`）。Windows 自带的 Tkinter 即可，
无需安装其它库；`启动打码工具.vbs` 会自动查找本机可用的 Python（含随附运行时）。
